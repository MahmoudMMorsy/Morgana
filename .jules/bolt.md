## 2024-07-17 - [Initial Profiling of MorganaPixel]
**Learning:** Found that the app uses two generation modes: a fast local offline generator using PyTorch model `MorganaPixelGenerator` (running fully on CPU, fast and low footprint), and a heavy Stable Diffusion model via diffusers. However, `MorganaPipeline.__init__` lacks the `use_sd` keyword argument expected by both `app.py` and `generate.py`. This prevents the application from starting in local mode or CLI mode, completely blocking the lightweight offline pipeline. Furthermore, dither mapping functions contain highly slow pure-Python nested loops and redundant array creations which can be heavily optimized using vectorization.
**Action:** Implement `use_sd` argument in `MorganaPipeline.__init__` to load `MorganaPixelGenerator` under `use_sd=False`. Optimize dithering algorithms with NumPy vectorization to eliminate overhead.
